The machine

the web.

An AI-native web scraper for in-house use. A customer asks for data from a set of websites — we point the machine at each URL and it discovers the schema, writes its own selectors, extracts, and validates, with humans only reviewing and refining. Every successful run teaches a per-domain cache, so the second run is free.

01

What we're solving

Why this exists / the bet behind it
The pain
Hand-built scrapers are expensive & brittle

Every site needs a developer to find selectors. Sites change, selectors break, the work never ends. Doesn't scale across hundreds of customer sources.

Our approach
AI configures the extractor, humans just review

Claude reads the page — screenshot, HTML, APIs, structured data — proposes the schema, writes XPaths & API paths, and cross-checks its own output against the screenshot.

The moat
A domain cache that makes repeats free

~$0.12 first run on a new domain → ~$0.00 every run after. 1,000 URLs on one template ≈ $0.12 total. The cache is an asset that compounds.

The extraction chain

URL in, structured data out — cheapest source first, AI only when needed. (hover a stage)
Input · a URL + requested fields → pipeline → Output · validated structured rows
0

Domain cache lookup

Scraped this domain + page type before? Cached paths are always consulted.

cache · free
1

Page capture

Playwright loads the page, dismisses popups (3 rounds), intercepts XHR/JSON, grabs JSON-LD / __NEXT_DATA__ / meta, screenshots, HTML→Markdown.

~5–20s
2

Mechanical extraction

Flatten intercepted APIs + JSON-LD + meta tags, match by field name & alias. No AI.

free
2.5

Cached paths + cross-validate

Replay stored dot-notation API paths & XPaths on the fresh page, then cross-validate all sources — majority wins, ranked by hit rate.

cache · free
3

AI API analysis ⟡ only for unresolved fields

Claude reads the raw API / scoped __NEXT_DATA__ JSON and returns a value + dot-path per missing field.

~$0.03
4

AI XPath / vision ⟡ last resort

Multimodal reverse-search: screenshot + HTML → an XPath and the value AI saw. If the XPath yields nothing, the AI-seen value ships as ai-vision.

~$0.05
5

Save to domain cache

Merge every working path with hit/miss stats. Accumulator — never overwritten. Dead paths auto-pruned (≥5 uses & ≤10% hits); max 5 paths/field.

enriches cache
↺ Each step only runs for fields the cheaper steps couldn't resolve — so a warm cache skips the paid AI calls entirely.
