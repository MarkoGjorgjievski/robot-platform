# Proxy support in the browser — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let staff give a website a proxy and a country, so every page of that website loads through the proxy with the country's locale and time zone, proven against a local recording proxy.

**Architecture:** `@robot/db` gains `sources.proxy_url` and makes `sources.country` a nullable `varchar(2)` (migration `0024`, which nulls the dead `'us'` values). `@robot/browser` gains the 20-market table (`countries.ts`), `BrowserOptions.proxy` / `locale` / `timezoneId` passed to `newContext` (a non-US locale gets its own stealth launcher, so stealth's `en-US` disguise does not override it), and a new `CaptureErrorKind` `'proxy'` ("The proxy refused the connection.") for a proxy that fails to connect or answers 407 — never retried direct. `@robot/api` gains `src/proxy/` — `proxy-url.ts` (validation, `{country}`, masking, `redactProxy`), `browser-profile.ts` (`buildProfile`, `networkOf`, `browserProfileForSource`) and `website-session.ts` (`forWebsite`) — and `withBrowserSession(fn, opts)` takes `opts.profile`; every website-scoped page load opens its browser through `forWebsite(sourceId)`. `sources.update` takes `proxyUrl` / `country` from operators only (logged in staff words, reworded for the customer), `sources.get` gives them to staff only, `ops.website` gains a `network` line. `@robot/app` gets a staff-only "Network (staff)" panel on a website's Settings and a Network cell on the ops website page. `packages/worker/src/live-proxy.ts` is the free live check.

**Tech Stack:** TypeScript ESM; Drizzle + Postgres (postgres-js), drizzle-kit; Playwright 1.62.1 + playwright-extra + puppeteer-extra-plugin-stealth (browser); tRPC v11 + zod 3 + superjson; vitest; TanStack Start/Router + React 19, Tailwind v4, shadcn/Radix select (app); Playwright (smokes).

## Global Constraints

- **What a website carries** (spec §2.1, verbatim): `sources.proxy_url text` (nullable) and `sources.country varchar(2)`. The existing `country` column is reused: a migration makes it nullable and sets the dead `'us'` default rows to null.
- **Proxy URL** (§2.1, verbatim): `http://`, `https://` or `socks5://`, optionally with `user:pass@`. It may contain the literal token `{country}`, which is replaced with the website's country (lower-case) at use. Example: `http://user-country-{country}:pass@gate.provider.com:7000`.
- **Country** (§2.1): an ISO 3166-1 alpha-2 code from a fixed table of 20 common markets, or null (no preference). The table is `browser/src/countries.ts`; each entry is `{ code, name, locale, timezoneId }`, for example `de → de-DE / Europe/Berlin`, `gb → en-GB / Europe/London`, `us → en-US / America/New_York`.
- **The env default** (§2.1): `DEFAULT_PROXY_URL`. A website with no proxy of its own uses it when it is set.
- **Validation at save** (§2.1, verbatim): the scheme is one of the three; there is a host and a port; total length is at most 1,000; `{country}` is the only token; no whitespace. A refusal is one plain staff sentence, for example **"Use an address like http://user:pass@host:port."**
- **Storage** (§2.1): the password lives in plain text in the URL, like the webhook secret. It is never logged: every log line and stored error goes through `redactProxy` (the userinfo becomes `***`).
- **The profile** (§2.2, verbatim): `browserProfileForSource(db, sourceId)` returns `{ proxy?: { server, username?, password? }; locale?; timezoneId? }`, built from the website's proxy URL (or `DEFAULT_PROXY_URL`) with `{country}` replaced, and from the country's locale and time zone. With no country: locale and time zone stay as today (stealth's `en-US` / New York). With no proxy: the proxy key is absent, and the browser goes direct as today.
- **The browser** (§2.2): `BrowserOptions` gains `proxy`, `locale` and `timezoneId`; `PlaywrightBrowser.launch()` passes them to `newContext`; an explicit `locale` / `timezoneId` wins over stealth's defaults. `withBrowserSession(fn, opts?)` gains `opts.profile`. Reachability and the listing check stay direct. Staff CLIs (the judge, `jev-images-run`) are unchanged.
- **A failing proxy** (§2.2, verbatim): a capture through a proxy that fails to connect, or answers 407, gets the verdict `blocked` with the staff sentence **"The proxy refused the connection."** The customer sentence for any blocked page is unchanged (`captureWords`).
- **Politeness** (§2.2): the domain lock stays keyed by host.
- **Who sets it** (§2.3, verbatim): staff only. In staff mode a website's Settings tab shows a **"Network (staff)"** section with two rows — **Proxy:** a URL field with the password masked once saved, plus Show, **"Use the default"** (clears the website's own URL) and Save; **Country:** a select from the table, with **"No preference"**. `sources.update` accepts `proxyUrl` and `country` only from an operator, or from staff in staff mode; anyone else gets `FORBIDDEN` for those fields. `sources.get`: staff get `proxyUrl` with the password masked (`http://user:•••@host:port`), a `proxyFromDefault: boolean`, and `country`; customers get neither key.
- **Logging** (§2.3, verbatim): a staff change is logged in staff words, for example **"Set the website's proxy"** or **"Set the website's country to Germany"**. The customer's log reads **"Changed a setting of this website"**. The money and procedure sweeps stay green; the procedure-classes table is unchanged (no procedure is added).
- **Ops** (§2.3, verbatim): the website detail (`/ops/websites/$id`) shows **"Network: proxy (own | default | none) · country"**.
- **What a customer sees** (§2.4): nothing new.
- **Safety properties** (§3, verbatim): 1. A website with a proxy never loads a page directly (no fallback to direct on a proxy failure). 2. A website's proxy credentials never reach a customer, a log or a stored error. 3. A website without a proxy behaves exactly as before, with the same locale and time zone. 4. Reachability and listing checks before a website exists are unchanged. 5. Nothing paid in tests or the live check.
- **Customer copy:** a customer never receives the word "proxy", a proxy address, a username or a password — in anything drawn or anything the browser receives. `packages/app/src/customer-copy-sweep.test.ts` gains `proxy` as a forbidden word (staff-only files exempt) and `packages/api/src/isolation/money-sweep.test.ts` gains a proxy sweep; both stay green.
- **No real proxy and no paid call in any test or check:** every proxy is `startRecordingProxy()` on 127.0.0.1 or an address under `.test` / `.invalid` that is never dialled; every process this plan starts runs with `ANTHROPIC_API_KEY= JEV_SHADOW= TYPESAFE_API_KEY= SMTP_URL= DEFAULT_PROXY_URL=`.

## Review Focus

1. **`{country}` in an address when the website has no country** (staff paste `http://u-country-{country}:p@gate:7000` and never pick a country; or `DEFAULT_PROXY_URL` names `{country}` and a website has none) — a person expects the save to be refused with one sentence for the website's own address, and for the default every page of that website to fail with "The proxy refused the connection." and the Network panel to say why — never a direct load, never a guessed country. → Task 3 test "RF1: {country} with no country never guesses and never goes direct"; Task 5 test "RF1: an own address with {country} needs a country, at save and when the country is cleared".
2. **A broken `DEFAULT_PROXY_URL`** (`gate.provider.com:7000` with no scheme, `http://gate` with no port, `socks5://u:p@gate:1080`, a space inside) — a person expects a bad default never to mean "no proxy": every website without its own address fails its pages with the proxy sentence, and staff read the reason on the Network panel. → Task 3 test "RF2: a broken default is a problem for every website that uses it, never a direct load".
3. **Reserved characters in the credentials** (a password `p@ss:w/rd` written encoded as `p%40ss%3Aw%2Frd`, or with a raw `@`) — a person expects the proxy to receive exactly that password, and the masked address, a log line and an error never to show any of it. → Task 3 test "RF3: encoded and raw reserved characters reach the browser decoded and never show"; Task 2 test "RF3: the proxy receives a password with reserved characters exactly".
4. **A customer's own call answered with the website row** (`sources.update` toggling Active, `sources.updateBinding` saving answers) after staff set a proxy — a person expects no proxy address, country or password in that answer either, only in staff's `sources.get`. → Task 5 test "RF4: a customer's own updates never answer with the proxy".
5. **A customer reading a page the proxy refused** (the proof card, a run's failed page, the run diagnosis) — a person expects the unchanged blocked sentence "This website turned us away, so we can't read it yet." and a `blocked` diagnosis, never the word "proxy". → Task 2: the "RF5" `proxy` row added to app `capture-words.test.ts`'s `CASES` (every host, every wrapper, `/proxy/i` in `LEAKS`) and the test "RF5: a proxy refusal diagnoses as blocked, in customer words for a customer" (app `diagnose-run.test.ts`).

// A tiny recording HTTP proxy for tests and the live check (spec 2026-10-24 proxy §4): absolute-URI requests are
// forwarded with FORWARDED_HEADER set, so the website can tell a proxied request from a direct one; CONNECT is
// tunnelled; every request is logged; Basic auth is optional (a wrong or missing Proxy-Authorization answers 407).
// Loopback only, never a real provider.
import { createServer, request as httpRequest, type IncomingHttpHeaders } from 'node:http';
import { connect, type AddressInfo, type Socket } from 'node:net';

export const FORWARDED_HEADER = 'x-test-proxy-forwarded';
export type ProxyLogEntry = { method: string; url: string; headers: IncomingHttpHeaders; allowed: boolean };
export type RecordingProxy = { url: string; port: number; log: ProxyLogEntry[]; close(): Promise<void> };

export async function startRecordingProxy(opts: { auth?: { username: string; password: string } } = {}): Promise<RecordingProxy> {
  const log: ProxyLogEntry[] = [];
  const expected = opts.auth ? `Basic ${Buffer.from(`${opts.auth.username}:${opts.auth.password}`).toString('base64')}` : null;
  const allowed = (h: IncomingHttpHeaders) => expected === null || h['proxy-authorization'] === expected;
  const sockets = new Set<Socket>();
  const server = createServer((req, res) => {
    const ok = allowed(req.headers);
    log.push({ method: req.method ?? '', url: req.url ?? '', headers: req.headers, allowed: ok });
    if (!ok) {
      res.writeHead(407, { 'proxy-authenticate': 'Basic realm="test"', 'content-type': 'text/plain' });
      res.end('proxy authentication required');
      return;
    }
    let target: URL;
    try { target = new URL(req.url ?? ''); } catch { res.writeHead(400).end(); return; }
    const headers: IncomingHttpHeaders = { ...req.headers, [FORWARDED_HEADER]: '1' };
    delete headers['proxy-authorization'];
    delete headers['proxy-connection'];
    const out = httpRequest({ host: target.hostname, port: target.port || 80, path: `${target.pathname}${target.search}`, method: req.method, headers }, (up) => {
      res.writeHead(up.statusCode ?? 502, up.headers);
      up.pipe(res);
    });
    out.on('error', () => { if (!res.headersSent) res.writeHead(502); res.end(); });
    req.pipe(out);
  });
  server.on('connect', (req, client: Socket, head: Buffer) => {
    const ok = allowed(req.headers);
    log.push({ method: 'CONNECT', url: req.url ?? '', headers: req.headers, allowed: ok });
    if (!ok) {
      client.end('HTTP/1.1 407 Proxy Authentication Required\r\nProxy-Authenticate: Basic realm="test"\r\nContent-Length: 0\r\n\r\n');
      return;
    }
    const [host, port] = (req.url ?? '').split(':');
    const up = connect(Number(port), host!, () => {
      client.write('HTTP/1.1 200 Connection Established\r\n\r\n');
      up.write(head);
      up.pipe(client);
      client.pipe(up);
    });
    up.on('error', () => client.destroy());
    client.on('error', () => up.destroy());
  });
  server.on('connection', (s: Socket) => { sockets.add(s); s.on('close', () => sockets.delete(s)); });
  await new Promise<void>((r) => server.listen(0, '127.0.0.1', () => r()));
  const port = (server.address() as AddressInfo).port;
  return {
    url: `http://127.0.0.1:${port}`,
    port,
    log,
    close: () => new Promise<void>((r) => { for (const s of sockets) s.destroy(); server.close(() => r()); }),
  };
}

const DEFAULT_LOCALE = 'en-US';
// No types ship for the evasions' own modules (CommonJS, default export = (opts) => plugin).
const UA_OVERRIDE = 'puppeteer-extra-plugin-stealth/evasions/user-agent-override/index.js';
const NAV_LANGUAGES = 'puppeteer-extra-plugin-stealth/evasions/navigator.languages/index.js';

/**
 * playwright-extra + the stealth plugin, loaded lazily and memoised — one launcher per locale.
 *
 * Lazy because it is a heavy import on a module every package pulls in, and
 * because a failure to load it must not take down capture entirely — a vanilla
 * browser that gets blocked on some sites beats no browser at all.
 *
 * With no locale (or en-US) it is exactly the launcher it always was (spec 2026-10-24 proxy §3.3). Another locale gets
 * its own instance (`addExtra`) whose `user-agent-override` and `navigator.languages` evasions carry that locale:
 * stealth's defaults would otherwise put en-US back over the context's locale on every page.
 */
const stealthLaunchers = new Map<string, Promise<typeof chromium>>();
function stealthChromium(locale?: string): Promise<typeof chromium> {
  const key = locale && locale !== DEFAULT_LOCALE ? locale : '';
  let launcher = stealthLaunchers.get(key);
  if (!launcher) {
    launcher = (async () => {
      try {
        const [{ chromium: shared, addExtra }, { default: StealthPlugin }] = await Promise.all([
          import('playwright-extra'),
          import('puppeteer-extra-plugin-stealth'),
        ]);
        if (!key) {
          shared.use(stealthPlugin(StealthPlugin));
          return shared as unknown as typeof chromium;
        }
        const extra = addExtra(chromium);
        const stealth = stealthPlugin(StealthPlugin);
        stealth.enabledEvasions.delete('user-agent-override');
        stealth.enabledEvasions.delete('navigator.languages');
        extra.use(stealth);
        const languages = [key, key.split('-')[0]!];
        const [{ default: UserAgentOverride }, { default: NavigatorLanguages }] = await Promise.all([
          import(UA_OVERRIDE as string) as Promise<{ default: (o: object) => Parameters<typeof extra.use>[0] }>,
          import(NAV_LANGUAGES as string) as Promise<{ default: (o: object) => Parameters<typeof extra.use>[0] }>,

        return chromium;
      }
    })();

// packages/api/src/proxy/proxy-url.ts
// A website's proxy address (spec 2026-10-24 proxy §2.1): http://, https:// or socks5://, optionally user:pass@, with
// `{country}` filled in at use. Checked at save in one staff sentence; the password is masked for staff (§2.3) and
// redacted from every log line and stored error (§3.2). Pure.
import type { ProxySettings } from '@robot/browser';

export const COUNTRY_TOKEN = '{country}';
export const PROXY_URL_MAX = 1000;
export const PROXY_URL_EXAMPLE = 'Use an address like http://user:pass@host:port.';
export const ONLY_COUNTRY_TOKEN = 'Only {country} can be filled in.';
/** Chromium takes no credentials for a socks5 proxy (Playwright refuses the context). */
export const SOCKS_NO_AUTH = 'A socks5 proxy cannot take a user and password here. Use http:// or https://, or socks5://host:port.';

export type ParsedProxy = { scheme: 'http' | 'https' | 'socks5'; host: string; port: number; username?: string; password?: string };

/** `scheme://[userinfo@]host:port[/]` — the userinfo runs to the LAST `@` (as WHATWG reads it), the port is explicit. */
const SHAPE = /^(https?|socks5):\/\/([^/?#]*)\/?$/i;
const HOST_PORT = /^(\[[0-9a-f:.]+\]|[^:@[\]]+):(\d{1,5})$/i;

const decode = (s: string): string | null => { try { return decodeURIComponent(s); } catch { return null; } };

/** The parts of an address with no `{country}` left in it; null when it is not one we can use. */
export function parseProxyUrl(url: string): ParsedProxy | null {
  const m = SHAPE.exec(url);
  if (!m) return null;
  const authority = m[2]!;
  const at = authority.lastIndexOf('@');
  const hp = HOST_PORT.exec(authority.slice(at + 1));
  if (!hp) return null;
  const port = Number(hp[2]);
  if (port < 1 || port > 65_535) return null;
  try { if (!new URL(url).hostname) return null; } catch { return null; }
  const out: ParsedProxy = { scheme: m[1]!.toLowerCase() as ParsedProxy['scheme'], host: hp[1]!, port };
  if (at >= 0) {
    const userinfo = authority.slice(0, at);
    const colon = userinfo.indexOf(':');
    const user = decode(colon >= 0 ? userinfo.slice(0, colon) : userinfo);
    const pass = colon >= 0 ? decode(userinfo.slice(colon + 1)) : undefined;
    if (user === null || pass === null) return null;
    if (user) out.username = user;
    if (pass !== undefined) out.password = pass;
  }
  return out;
}

/** The save-time check (spec §2.1): the scheme, a host and a port, ≤ 1,000 characters, `{country}` the only token, no whitespace. */
export function checkProxyUrl(raw: string): { ok: true; url: string } | { ok: false; message: string } {
  const url = raw.trim();
  if (url === '' || url.length > PROXY_URL_MAX || /\s/.test(url)) return { ok: false, message: PROXY_URL_EXAMPLE };
  if (/[{}]/.test(url.split(COUNTRY_TOKEN).join(''))) return { ok: false, message: ONLY_COUNTRY_TOKEN };
  const parsed = parseProxyUrl(url.split(COUNTRY_TOKEN).join('xx'));
  if (!parsed) return { ok: false, message: PROXY_URL_EXAMPLE };
  if (parsed.scheme === 'socks5' && (parsed.username !== undefined || parsed.password !== undefined)) return { ok: false, message: SOCKS_NO_AUTH };
  return { ok: true, url };
}

/** What Playwright gets (spec §2.2): `{country}` replaced lower-case; null when the address does not check or needs a country it has not got. */
export function proxySettingsFor(url: string, countryCode: string | null): ProxySettings | null {
  if (!checkProxyUrl(url).ok) return null;
  if (url.includes(COUNTRY_TOKEN) && !countryCode) return null;
  const parsed = parseProxyUrl(url.trim().split(COUNTRY_TOKEN).join((countryCode ?? '').toLowerCase()));
  if (!parsed) return null;
  return {
    server: `${parsed.scheme}://${parsed.host}:${parsed.port}`,
    ...(parsed.username !== undefined ? { username: parsed.username } : {}),
    ...(parsed.password !== undefined ? { password: parsed.password } : {}),
  };
}

/** For staff (spec §2.3): `http://user:•••@host:port` — the password never leaves the server. */
export function maskProxyUrl(url: string): string {
  const m = /^([a-z0-9]+:\/\/)([^/?#]*)(.*)$/i.exec(url.trim());
  if (!m) return url;
  const authority = m[2]!;
  const at = authority.lastIndexOf('@');
  if (at < 0) return url.trim();
  const userinfo = authority.slice(0, at);
  const colon = userinfo.indexOf(':');
  const user = colon >= 0 ? userinfo.slice(0, colon) : userinfo;
  return `${m[1]}${user}${colon >= 0 ? ':•••' : ''}@${authority.slice(at + 1)}${m[3]}`;
}

/** Every log line and stored error (spec §2.1 "Storage"): the userinfo of each proxy address becomes `***`. */
export function redactProxy(text: string): string {
  return text.replace(/\b(https?|socks5):\/\/[^\s/?#]*@/gi, (_m, scheme: string) => `${scheme}://***@`);
}

// packages/api/src/proxy/browser-profile.ts
// A website's browser (spec 2026-10-24 proxy §2.2): its own proxy address, else DEFAULT_PROXY_URL, with `{country}`
// filled in, and its country's locale and time zone. An address that cannot be used is a proxy failure — the capture
// fails with "The proxy refused the connection." and the staff reason — never a direct load (§3.1).
import { eq } from 'drizzle-orm';
import { CaptureError, countryByCode, type BrowserProfile } from '@robot/browser';
import { sources, type Database } from '@robot/db';
import { checkProxyUrl, COUNTRY_TOKEN, maskProxyUrl, proxySettingsFor, redactProxy } from './proxy-url.js';

export const NEEDS_COUNTRY = "This website's proxy address fills in {country}, so it needs a country.";

type Site = { proxyUrl: string | null; country: string | null };
const blank = (s: string | null | undefined) => !s || s.trim() === '';

/** The staff reason this website's address cannot be used, or null. */
function problemOf(own: string | null, fallback: string | null, hasCountry: boolean): string | null {
  const url = own ?? fallback;
  if (!url) return null;
  const where = own ? "This website's proxy address" : 'DEFAULT_PROXY_URL';
  const checked = checkProxyUrl(url);
  if (!checked.ok) return redactProxy(`${where} is not usable: ${checked.message}`);
  if (url.includes(COUNTRY_TOKEN) && !hasCountry) return own ? NEEDS_COUNTRY : 'DEFAULT_PROXY_URL fills in {country}, and this website has no country.';
  return null;
}

export function buildProfile(site: Site, defaultUrl: string | undefined = process.env.DEFAULT_PROXY_URL): BrowserProfile {
  const country = countryByCode(site.country);
  const profile: BrowserProfile = country ? { locale: country.locale, timezoneId: country.timezoneId } : {};
  const own = blank(site.proxyUrl) ? null : site.proxyUrl!.trim();
  const fallback = blank(defaultUrl) ? null : defaultUrl!.trim();
  const url = own ?? fallback;
  if (!url) return profile;
  const problem = problemOf(own, fallback, !!country);
  if (problem) throw new CaptureError('proxy', '', problem);
  return { ...profile, proxy: proxySettingsFor(url, country?.code ?? null)! };
}

export type Network = { proxy: 'own' | 'default' | 'none'; proxyUrl: string | null; country: string | null; countryName: string | null; problem: string | null };

/** What staff read (spec §2.3): own, the default or none, the address masked, the country, and why it cannot be used. */
export function networkOf(site: Site, defaultUrl: string | undefined = process.env.DEFAULT_PROXY_URL): Network {
  const country = countryByCode(site.country);
  const own = blank(site.proxyUrl) ? null : site.proxyUrl!.trim();
  const fallback = blank(defaultUrl) ? null : defaultUrl!.trim();
  const url = own ?? fallback;
  return {
    proxy: own ? 'own' : fallback ? 'default' : 'none',
    proxyUrl: url ? maskProxyUrl(url) : null,
    country: country?.code ?? null,
    countryName: country?.name ?? null,
    problem: problemOf(own, fallback, !!country),
  };
}

/** The profile a website's browser session opens with (spec §2.2). An unknown website: `{}` (direct, as before). */
export async function browserProfileForSource(db: Database, sourceId: string): Promise<BrowserProfile> {
  const row = await db.query.sources.findFirst({ where: eq(sources.id, sourceId), columns: { proxyUrl: true, country: true } });
  return row ? buildProfile(row) : {};
}

// packages/api/src/proxy/website-session.ts
// A website's browser session (spec 2026-10-24 proxy §2.2): every page load for a website opens its browser through
// this, with the website's proxy, locale and time zone read as the session opens. Reachability and the listing check —
// which run before a website exists — call `withBrowserSession` directly and stay direct (§3.4).
import type { IBrowser } from '@robot/browser';
import { db } from '@robot/db';
import { withBrowserSession } from '../browser-session.js';
import { browserProfileForSource } from './browser-profile.js';

export type WebsiteSession = <T>(fn: (browser: IBrowser) => Promise<T>) => Promise<T>;

/** `session`: the one to open (tests inject a fake one; the drift check and proof-page capture pass theirs through). */
export function forWebsite(sourceId: string, session: typeof withBrowserSession = withBrowserSession): WebsiteSession {
  return async <T,>(fn: (browser: IBrowser) => Promise<T>): Promise<T> => {
    // An address that cannot be used throws the proxy CaptureError here, before any browser opens (spec §3.1).
    const profile = await browserProfileForSource(db, sourceId);
    return session(fn, { profile });
  };
}

// The Network (staff) panel on a website's Settings (spec 2026-10-24 proxy §2.3). Staff only: the server sends these
// fields to staff alone (`sources.get`), and the panel is drawn only when they are there. Pure.

export type NetworkSettings = {
  /** Masked by the server: http://user:•••@host:port. */
  proxyUrl: string | null;
  proxyFromDefault: boolean;
  country: string | null;
  countries: Array<{ code: string; name: string }>;
  /** Why the address cannot be used (pages fail with "The proxy refused the connection."), or null. */
  problem: string | null;
};

export const NETWORK_TITLE = 'Network (staff)';
export const NETWORK_HELP =
  "Every page of this website loads through this proxy, as if from this country. The address check when a website is added and the listing page check go direct. Use {country} in the address for the website's country.";
export const NO_COUNTRY = 'none';
export const NO_COUNTRY_LABEL = 'No preference';

export function proxyStateLine(n: Pick<NetworkSettings, 'proxyUrl' | 'proxyFromDefault'>): string {
  if (!n.proxyUrl) return 'No proxy: pages load directly.';
  return n.proxyFromDefault ? `The default: ${n.proxyUrl}` : `This website's own: ${n.proxyUrl}`;
}

/** Why Save is off (said beside it), or null. The server's own sentences say the rest. */
export function proxySaveReason(typed: string): string | null {
  return typed.trim() === '' ? 'Type a proxy address to save' : null;
}

/** Why "Use the default" is off, or null. */
export function useDefaultReason(n: Pick<NetworkSettings, 'proxyUrl' | 'proxyFromDefault'>): string | null {
  return n.proxyUrl && !n.proxyFromDefault ? null : 'This website has no address of its own';
}

export function countryChoices(countries: NetworkSettings['countries']): Array<{ value: string; label: string }> {
  return [
    { value: NO_COUNTRY, label: NO_COUNTRY_LABEL },
    ...[...countries].sort((a, b) => a.name.localeCompare(b.name)).map((c) => ({ value: c.code, label: c.name })),
  ];
}

export function countryFromChoice(value: string): string | null {
  return value === NO_COUNTRY ? null : value;
}

## Settled here (spec ambiguities, decided for this plan)

1. **The migration touches Marko's rows.** It sets `sources.country` to null where it was `'us'` (any case) or not two letters long — the spec's "nulls the dead 'us' values"; the column was never read and always `'us'`, so no information is lost. It is applied to the dev database in Task 1 (the api tests need the new column there), after a `pg_dump -t sources`; `main`'s code still writes `'us'` into it without error. The statements are reordered by hand (drop NOT NULL, null the values, then `varchar(2)`), because drizzle-kit's order would fail on a longer value. No check constraint on the letters: thirty test files still insert `'US'`, which now reads as the United States (the same locale and zone as no preference).
2. **"The verdict `blocked`" is a `CaptureError` of a new kind `'proxy'`**, not a new `CaptureVerdict`: a page the proxy would not carry is a page whose document never came from the website. Its message is the staff sentence "The proxy refused the connection."; `captureWords` maps it to the unchanged blocked sentence ("This website turned us away, so we can't read it yet."), and the run diagnosis reads it as `blocked`. It never starts a host backoff (`reportVerdict` backs off only on refusals and challenges: the website did not refuse us). A 407 main response and Chromium's proxy/tunnel net errors are both this kind, from every navigation (`capture`, `evaluate`, `crawl`, `scrollPages`), and only when the browser has a proxy.
3. **A proxy address that cannot be used is a proxy failure, never "no proxy".** A broken `DEFAULT_PROXY_URL`, an own address that no longer checks, or `{country}` with no country: the profile builder throws the same `CaptureError('proxy')` (staff reason in its `detail`, redacted), so the website's pages fail before any browser opens; staff read the reason on the Network panel (`networkProblem`). `{country}` is never guessed. At save, an own address with `{country}` needs a country (and the country cannot then be cleared); the default's `{country}` is the operator's to keep consistent (said in `CLAUDE.md`).
4. **The address rules, made exact:** trimmed first; no path, query or fragment (a trailing `/` is allowed); the port explicit and 1–65535; the userinfo runs to the last `@` (as browsers read it) and is percent-decoded (a broken escape is refused); `socks5://` with a user or password is refused with its own sentence — Chromium cannot authenticate a socks5 proxy and Playwright refuses the context. Refusals: "Use an address like http://user:pass@host:port." (the spec's), "Only {country} can be filled in.", the socks5 sentence, "Choose a country from the list.", and "This website's proxy address fills in {country}, so it needs a country."
5. **A customer's call with `proxyUrl` or `country` is refused whole** (`FORBIDDEN`, "Operators only", nothing written); calls without those fields work as before. "Operator, or staff in staff mode" is `ctx.isOperator` (a staff session's user is an operator), as for the monthly limit. Only staff-mode changes are logged (the existing middleware).
6. **What `sources.get` sends staff:** besides the spec's `proxyUrl` (masked: the effective address — own or the default), `proxyFromDefault` and `country`, also `countries` (the table, for the select — the shipped app imports nothing from `@robot/browser`) and `networkProblem`. A customer receives none of the five keys; no mutation answer carries the row's `proxyUrl` or `country` for anyone (`withoutNetwork` on `sources.update` and `sources.updateBinding`, which returned the whole row).
7. **"Masked once saved, plus Show":** the server never sends the saved password, so the saved address is shown masked as a line, and the field is for a new address — empty, password-style, with Show revealing what is being typed. "Use the default" clears the website's own address (off, with its reason, when there is none).
8. **Staff words:** "Set the website's proxy", "Set the website's proxy to the default", "Set the website's country to Germany", "Set the website's country to no preference" (two in one call are joined with ". "); the customer reads every one as "Changed a setting of this website" (`customerSummary`). Ops: "proxy (own | default | none) · <country name>", "no country" for none.
9. **Where the profile applies:** every worker job for a website (the audit above), through `forWebsite`; a scan test keeps it that way. Direct by design: reachability and the listing check (the spec), the staff CLIs (judge, `jev-images-run`, dogfood) and the dated staff scripts in `api/src/scripts/` (two of them read many websites in one session) — named in the handoff's Open list. `setContentEvaluate`'s offline context has no proxy (it aborts every request).
10. **Accepted, not fixed:** Playwright (1.62) answers every HTTP auth challenge in a proxied context with the proxy's credentials (it cannot tell a website's 401 from the proxy's 407), so a website that asks for a password would receive them. No option scopes them; it goes to Needs Marko with the advice to use gateway-only credentials or an allow-listed proxy.
11. **Locale under stealth:** stealth's `user-agent-override` and `navigator.languages` evasions hard-code en-US and would put it back over the context's locale; a non-US locale therefore launches from its own `addExtra(chromium)` instance with those two evasions given the locale (`de-DE,de`). No locale (or en-US) uses the launcher it always did — §3.3. The time zone needs nothing from stealth.
