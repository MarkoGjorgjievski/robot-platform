# Run speed — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A certified run captures each product lean (no popup rounds, no pictures, no second render; today's full capture only on a miss, a not-shown flag, a non-wall verdict or a check item), paces each host start to start, and runs several websites at once through the worker — measured on a local 1,000-page fixture as an order of magnitude faster with the same values.

**Architecture:** `@robot/browser`'s `capture()` gains `lean`, `pictures` and `finalProbe` options. `@robot/scraper` gets `verify/lean-run.ts` (the per-run state and the pure fallback/learning rules) and `runVerifiedExtraction` takes a lean capture first and today's full capture when the rules say so; the domain lock spaces page starts, not page ends. `@robot/api` threads one `LeanRunState` per run execution into `extractItem` and records the outcome on the capture row; the browser gate keeps one browser for background work as well as one for interactive. `@robot/worker` gets new defaults and a benchmark (`src/bench/`): a deterministic local shop, a throwaway database, an in-process worker.

**Tech Stack:** TypeScript ESM; Playwright via `@robot/browser`; Drizzle + Postgres (postgres-js); vitest; tsx.

**Spec:** `docs/superpowers/specs/2026-10-23-run-speed-design.md`

## Review Focus

1. **A lean value that is present but different** (a "Read more" text the expand pass would have swapped, a positional XPath shifted by a popup the full capture removes) — no miss rule sees it; a reasonable person expects the run to notice and stop trusting lean on that website. → Task 4 test "a check item whose lean value differs writes the full value and switches the run to full".
2. **A wall on the lean load** — a person expects one request, the host's backoff fed once, the item failed with its sentence; never a second load of a walled page. → Task 4 test "a lean wall is thrown with its sentence and never loaded twice".
3. **A field that is genuinely absent on some products** (rating missing) — a person expects the run to stay fast after a few products, not pay a full capture on every such page. → Task 4 test "three confirmed misses: the field's next lean miss is trusted".
4. **A rescued miss and path stats** — the lean miss must not count against a healthy path when the full capture found the value. → Task 4 test "lean+full: data, shown and stats all come from the full capture".
5. **A customer's Verify while four runs hold browsers** — a person expects their Verify to start, not wait for hours. → Task 6 test "runs hold at most max − 2: a background job still gets a browser".

```ts
// 127.0.0.(11+s) — its own hostname, so the domain lock paces it as its own host. Products /p/<id> carry JSON-LD,
// meta, an API the page fetches, XPath-only fields, a "Read more" description, a details panel, popups and
// latency shaped like the real product pages measured on 2026-10-23. Free; loopback only.
import { createServer, type IncomingMessage, type ServerResponse, type Server } from 'node:http';

export type FixtureLatency = { htmlMs: [number, number]; slowExtraMs: number; slowShare: number; cssMs: number; imageMs: number; apiMs: [number, number] };
/** ~2 s to `load`, like the real pages: HTML 0.6–0.9 s (5 % +2.5 s), a render-blocking stylesheet, three images. */
export const REALISTIC: FixtureLatency = { htmlMs: [600, 900], slowExtraMs: 2500, slowShare: 0.05, cssMs: 300, imageMs: 1200, apiMs: [300, 900] };
export const INSTANT: FixtureLatency = { htmlMs: [0, 0], slowExtraMs: 0, slowShare: 0, cssMs: 0, imageMs: 0, apiMs: [0, 0] };

export type FixtureSite = { index: number; host: string; origin: string; consentGated: boolean; productUrl(id: number): string };
export type FixtureShop = { sites: FixtureSite[]; close(): Promise<void> };

/** A deterministic number in [0, 1) for (site, id, salt). */
export function unit(site: number, id: number, salt: string): number {
  let h = 2166136261;
  for (const ch of `${site}:${id}:${salt}`) { h ^= ch.charCodeAt(0); h = Math.imul(h, 16777619); }
  return ((h >>> 0) % 10_000) / 10_000;
}
const between = ([lo, hi]: [number, number], u: number) => Math.round(lo + (hi - lo) * u);
const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));
const esc = (s: string) => s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');

export type ProductTruth = {
  title: string; sku: string; price: string; brand: string; stock: string; rating: string | null;
  description: string; materials: string; cookie: boolean; newsletter: boolean; readMore: boolean;
};
export type TruthKey = 'title' | 'sku' | 'price' | 'brand' | 'stock' | 'rating' | 'description' | 'materials';

export function product(site: number, id: number): ProductTruth {
  const readMore = id % 3 === 0;
  return {
    title: `Fixture ${site}-${id} Lamp`,
    sku: `FX-${site}-${id}`,
    price: (9.99 + ((site * 31 + id * 7) % 200)).toFixed(2),
    brand: `Brand ${(site + id) % 7}`,
    stock: (site * 3 + id) % 11 === 0 ? 'Sold out' : 'In stock',
    rating: id % 10 === 7 ? null : (3 + ((site + id) % 20) / 10).toFixed(1),
    description: readMore ? `The long story of lamp ${site}-${id}, told in full once you ask for it.` : `Lamp ${site}-${id}, short and sweet.`,
    materials: `Steel ${(id * 13) % 100}%, glass`,
    cookie: unit(site, id, 'cookie') < 0.5,
    newsletter: unit(site, id, 'news') < 0.2,
    readMore,
  };
}

export type FixtureField = { name: string; type: CustomerFieldType; truth: TruthKey; paths: CertifiedPath[] };
const p = (source: CertifiedPath['source'], path: string): CertifiedPath => ({ source, path, transform: 'identity' });
export const FIXTURE_FIELDS: FixtureField[] = [
  { name: 'Title', type: 'text', truth: 'title', paths: [p('json-ld', 'name')] },
  { name: 'SKU', type: 'text', truth: 'sku', paths: [p('json-ld', 'sku')] },
  { name: 'Price', type: 'money', truth: 'price', paths: [p('api', 'price'), p('json-ld', 'offers.price')] },
  { name: 'Brand', type: 'text', truth: 'brand', paths: [p('xpath', '//div[@class="brand"]')] },
  { name: 'Stock', type: 'text', truth: 'stock', paths: [p('xpath', '//div[@id="stock"]')] },
  { name: 'Rating', type: 'number', truth: 'rating', paths: [p('xpath', '//div[@class="rating"]/span[@class="score"]')] },
  { name: 'Description', type: 'text', truth: 'description', paths: [p('xpath', '//div[@class="desc"]/p[@class="text"]')] },
  { name: 'Materials', type: 'text', truth: 'materials', paths: [p('xpath', '//details/p[@class="materials"]')] },
];

/** What a run should write per field name: the truth rendered the way `runVerifiedExtraction` renders a hit. */
export function renderedTruth(t: ProductTruth): Record<string, unknown> {
  const out: Record<string, unknown> = {};
  for (const f of FIXTURE_FIELDS) {
    const raw = t[f.truth];
    if (raw === null) { out[f.name] = null; continue; }
    if (f.type === 'text') { out[f.name] = String(raw).normalize('NFKC').replace(/\s+/g, ' ').trim(); continue; }
    const n = normalize(f.type, raw);
    out[f.name] = n === null ? null : renderValue(f.type, n);
  }
  return out;
}

const SVG = '<svg xmlns="http://www.w3.org/2000/svg" width="300" height="300"><rect width="300" height="300" fill="#ccc"/></svg>';

function handler(site: FixtureSite, lat: FixtureLatency) {
  return async (req: IncomingMessage, res: ServerResponse) => {
    const path = new URL(req.url ?? '/', site.origin).pathname;
    let m: RegExpMatchArray | null;
    if ((m = path.match(/^\/p\/(\d+)$/))) {
      const id = Number(m[1]);
      const slow = unit(site.index, id, 'slow') < lat.slowShare;
      await sleep(between(lat.htmlMs, unit(site.index, id, 'html')) + (slow ? lat.slowExtraMs : 0));
      res.writeHead(200, { 'content-type': 'text/html; charset=utf-8' });
      return res.end(productHtml(site, id, product(site.index, id)));
    }
    if ((m = path.match(/^\/api\/product\/(\d+)$/))) {
      const id = Number(m[1]);
      const t = product(site.index, id);
      await sleep(between(lat.apiMs, unit(site.index, id, 'api')));
      res.writeHead(200, { 'content-type': 'application/json' });
      return res.end(JSON.stringify({ id, name: t.title, price: t.price, stock: t.stock === 'In stock', note: 'fixture product payload for the run-speed benchmark' }));
    }
    if (path === '/static/site.css') {
      await sleep(lat.cssMs);
      res.writeHead(200, { 'content-type': 'text/css', 'cache-control': 'max-age=3600' });
      return res.end('body{font-family:sans-serif;max-width:960px;margin:0 auto}.price{font-weight:bold}');
    }
    if (path.startsWith('/img/')) {
      await sleep(lat.imageMs);
      res.writeHead(200, { 'content-type': 'image/svg+xml' });
      return res.end(SVG);
    }
    res.writeHead(404, { 'content-type': 'text/plain' });
    res.end('not found');
  };
}

export async function startFixtureShop(opts: { sites: number; latency?: FixtureLatency }): Promise<FixtureShop> {
  const lat = opts.latency ?? REALISTIC;
  const servers: Server[] = [];
  const sites: FixtureSite[] = [];
  for (let i = 0; i < opts.sites; i++) {
    const host = `127.0.0.${11 + i}`;
    const site: FixtureSite = { index: i, host, origin: '', consentGated: opts.sites >= 4 && i === opts.sites - 1, productUrl: (id) => `${site.origin}/p/${id}` };
    const server = createServer((req, res) => { void handler(site, lat)(req, res); });
    await new Promise<void>((resolve, reject) => { server.once('error', reject); server.listen(0, host, () => resolve()); });
    site.origin = `http://${host}:${(server.address() as AddressInfo).port}`;
    servers.push(server);
    sites.push(site);
  }
  return {
    sites,
    close: async () => { await Promise.all(servers.map((s) => new Promise<void>((r) => { s.closeAllConnections(); s.close(() => r()); }))); },
  };
}
```

```ts
import postgres from 'postgres';
import { drizzle } from 'drizzle-orm/postgres-js';
import { migrate } from 'drizzle-orm/postgres-js/migrator';

const here = fileURLToPath(new URL('.', import.meta.url));
const MIGRATIONS = join(here, '..', '..', '..', 'db', 'drizzle');

export function databaseUrl(base: string, name: string): string {
  const u = new URL(base);
  u.pathname = `/${name}`;
  return u.toString();
}

async function admin<T>(base: string, fn: (sql: postgres.Sql) => Promise<T>): Promise<T> {
  const sql = postgres(databaseUrl(base, 'postgres'), { max: 1, onnotice: () => {} });
  try { return await fn(sql); } finally { await sql.end(); }
}

export async function createBenchDatabase(base: string): Promise<{ name: string; url: string; drop(): Promise<void> }> {
  const stamp = Date.now();
  const name = `robot_bench_${stamp}`;
  await admin(base, async (sql) => {
    const old = await sql<{ datname: string }[]>`SELECT datname FROM pg_database WHERE datname LIKE 'robot_bench_%'`;
```

```ts
// and modes from `captures.metadata`, peak memory of the bench's own Chromium, and every written value.
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';
import { asc, eq, inArray } from 'drizzle-orm';
import { db, runs, runItems, extractions, captures, jobs } from '@robot/db';
import { BROWSER_OWNER_SWITCH } from '@robot/browser';

const run = promisify(execFile);
type Proc = { pid: number; ppid: number; mb: number; cmd: string };

async function processes(): Promise<Proc[]> {
  if (process.platform === 'win32') {
    const { stdout } = await run('powershell.exe', ['-NoProfile', '-NonInteractive', '-Command',
      'Get-CimInstance Win32_Process | Select-Object ProcessId,ParentProcessId,WorkingSetSize,CommandLine | ConvertTo-Json -Compress'], { windowsHide: true, maxBuffer: 64 * 1024 * 1024 });
    const rows = JSON.parse(stdout) as Array<{ ProcessId: number; ParentProcessId: number; WorkingSetSize: number; CommandLine: string | null }>;
    return rows.map((r) => ({ pid: r.ProcessId, ppid: r.ParentProcessId, mb: Number(r.WorkingSetSize) / 1_048_576, cmd: r.CommandLine ?? '' }));
  }
  const { stdout } = await run('ps', ['-eo', 'pid=,ppid=,rss=,args='], { maxBuffer: 64 * 1024 * 1024 });
  return stdout.split('\n').map((l) => l.trim()).filter(Boolean).map((l) => {
    const [pid, ppid, rss, ...rest] = l.split(/\s+/);
    return { pid: Number(pid), ppid: Number(ppid), mb: Number(rss) / 1024, cmd: rest.join(' ') };
  });
}

/** Working set of every Chromium this process launched (`--robot-owner=<ownerPid>`) and all of their children, in MB. */
export async function chromiumMb(ownerPid: number): Promise<number> {
  const all = await processes();
  const owned = new Set(all.filter((p) => p.cmd.includes(`${BROWSER_OWNER_SWITCH}${ownerPid}`)).map((p) => p.pid));
  let grew = true;
  while (grew) { grew = false; for (const p of all) if (!owned.has(p.pid) && owned.has(p.ppid)) { owned.add(p.pid); grew = true; } }
  return Math.round(all.filter((p) => owned.has(p.pid)).reduce((s, p) => s + p.mb, 0));
}

export function startMemorySampler(ownerPid: number, everyMs = 5000) {
  let chromiumPeakMb = 0; let nodePeakMb = 0; let samples = 0; let stopped = false;
  const loop = (async () => {
    while (!stopped) {
      chromiumPeakMb = Math.max(chromiumPeakMb, await chromiumMb(ownerPid).catch(() => 0));
      nodePeakMb = Math.max(nodePeakMb, Math.round(process.memoryUsage().rss / 1_048_576));
      samples++;
      await new Promise((r) => setTimeout(r, everyMs));
    }
  })();
  return { stop: async () => { stopped = true; await loop; return { chromiumPeakMb, nodePeakMb, samples }; } };
}

const pct = (xs: number[], q: number) => { if (xs.length === 0) return 0; const s = [...xs].sort((a, b) => a - b); return s[Math.min(s.length - 1, Math.floor(q * s.length))]!; };
export const stats = (xs: number[]) => ({ median: pct(xs, 0.5), p90: pct(xs, 0.9), mean: xs.length ? Math.round(xs.reduce((a, b) => a + b, 0) / xs.length) : 0 });

export type PageValues = { data: Record<string, unknown>; shown: Record<string, unknown> };
export type Collected = {
  wallMs: number; done: number; failed: number; cyclesMs: number[]; captureMs: number[];
  modes: Record<string, number>; values: Record<string, PageValues>;
  truth: { checked: number; mismatches: Array<{ page: string; field: string; got: unknown; want: unknown }> };
};

/** Reads back what the runs wrote. `t0`: when the worker started (every run job was already queued). */
export async function collectRun(seeded: SeededSite[], t0: number): Promise<Collected> {
  const out: Collected = { wallMs: 0, done: 0, failed: 0, cyclesMs: [], captureMs: [], modes: {}, values: {}, truth: { checked: 0, mismatches: [] } };
  let lastEnd = t0;
  for (const s of seeded) {
    const r = await db.query.runs.findFirst({ where: eq(runs.id, s.runId), columns: { jobId: true, completedAt: true } });
    const job = r?.jobId ? await db.query.jobs.findFirst({ where: eq(jobs.id, r.jobId), columns: { startedAt: true } }) : null;
    let prev = job?.startedAt?.getTime() ?? t0;
    const names = Object.fromEntries(Object.entries(s.keys).map(([name, key]) => [key, name]));
    const items = await db.select().from(runItems).where(eq(runItems.runId, s.runId)).orderBy(asc(runItems.completedAt));
    for (const it of items) {
      if (it.status === 'failed') out.failed++;
      if (it.status !== 'done' || !it.completedAt || !it.extractionId) continue;
      out.done++;
      const end = it.completedAt.getTime();
      out.cyclesMs.push(end - prev); prev = end; lastEnd = Math.max(lastEnd, end);
      const ex = await db.query.extractions.findFirst({ where: eq(extractions.id, it.extractionId) });
      const cap = ex?.captureId ? await db.query.captures.findFirst({ where: eq(captures.id, ex.captureId), columns: { metadata: true } }) : null;
      const meta = (cap?.metadata ?? {}) as { capture?: { totalMs?: number }; lean?: { mode: string; reason: string | null } };
      if (meta.capture?.totalMs !== undefined) out.captureMs.push(meta.capture.totalMs);
      const mode = meta.lean ? `${meta.lean.mode}${meta.lean.reason ? `:${meta.lean.reason}` : ''}` : 'none';
      out.modes[mode] = (out.modes[mode] ?? 0) + 1;
      const row = ((ex?.data as Array<Record<string, unknown>> | null) ?? [])[0] ?? {};
      const vr = (ex?.validationResult ?? {}) as { shown?: Record<string, unknown> };
      const id = Number(new URL(it.url).pathname.split('/').pop());
      const data: Record<string, unknown> = {}; const shown: Record<string, unknown> = {};
      for (const [key, name] of Object.entries(names)) { data[name] = row[key] ?? null; shown[name] = vr.shown?.[key] ?? null; }
      const page = `${s.site}/${id}`;
      out.values[page] = { data, shown };
      const want = renderedTruth(product(s.site, id));
      for (const [field, w] of Object.entries(want)) {
        out.truth.checked++;
        if (JSON.stringify(data[field]) !== JSON.stringify(w)) out.truth.mismatches.push({ page, field, got: data[field], want: w });
      }
    }
  }
  out.wallMs = lastEnd - t0;
  return out;
}

export async function waitForRuns(runIds: string[], deadlineMs: number): Promise<void> {
  const until = Date.now() + deadlineMs;
  const terminal = new Set(['completed', 'partial', 'failed', 'cancelled']);
  for (;;) {
    const rows = await db.select({ status: runs.status }).from(runs).where(inArray(runs.id, runIds));
    if (rows.length === runIds.length && rows.every((r) => terminal.has(r.status))) return;
    if (Date.now() > until) throw new Error(`bench: runs not finished after ${Math.round(deadlineMs / 60_000)} min: ${rows.map((r) => r.status).join(', ')}`);
    await new Promise((r) => setTimeout(r, 2000));
  }
}
```

```ts
// When a certified run's lean read is enough (spec 2026-10-23 run speed §3.3–3.4). One state per run execution:
// the first items are checked both ways; a miss or a not-shown flag takes today's full capture; three rescues in a
// row, or any disagreement, switch the rest of the run to the full capture; a field whose lean misses the full
// capture confirmed three times is trusted. Pure — runVerifiedExtraction owns the captures.
import type { Shown } from './shown-on-page.js';

export const LEAN_CHECK_ITEMS = 2;
export const LEAN_RESCUE_STREAK = 3;
export const LEAN_CONFIRM_STREAK = 3;
export const LEAN_FIRST_PATH_MS = 1_500;

export type LeanReason = 'check' | 'miss' | 'unshown' | 'verdict' | 'switched' | 'off';
type FallbackReason = 'check' | 'miss' | 'unshown' | 'verdict';
/** What one item took — `captures.metadata.lean` (spec §3.5). `fields`: what triggered the fallback, or what a check item disagreed on. */
export type LeanOutcome = { mode: 'lean' | 'full' | 'lean+full'; reason: LeanReason | null; fields: string[]; leanMs: number | null };
/** One field as one capture read it: `value` before defaults (null: no path read), its shown flag, and whether it has paths at all. */
export type FieldReading = { key: string; value: unknown; shown: Shown; hasPaths: boolean };

export type LeanRunState = {
  mode: 'lean' | 'full';
  /** Why the run takes the full capture: switched part-way, or turned off by RUN_CAPTURE=full. */
  why: 'switched' | 'off' | null;
  /** The one sentence for the log when switched. */
  note: string | null;
  checksLeft: number;
  rescueStreak: number;
  /** Per field: confirmations since its last rescue. */
  confirmed: Map<string, number>;
  counts: { lean: number; leanFull: Record<FallbackReason, number>; full: number };
};

export function newLeanRunState(opts: { off?: boolean; checks?: number } = {}): LeanRunState {
  return {
    mode: opts.off ? 'full' : 'lean', why: opts.off ? 'off' : null, note: null,
    checksLeft: opts.checks ?? LEAN_CHECK_ITEMS, rescueStreak: 0, confirmed: new Map(),
    counts: { lean: 0, leanFull: { check: 0, miss: 0, unshown: 0, verdict: 0 }, full: 0 },
  };
}

/** `RUN_CAPTURE=full` turns lean captures off for every run this process executes (the kill switch, spec §3.4). */
export function leanRunStateFromEnv(env: Record<string, string | undefined> = process.env): LeanRunState {
  return newLeanRunState({ off: (env.RUN_CAPTURE ?? '').trim().toLowerCase() === 'full' });
}

const trusted = (s: LeanRunState, key: string) => (s.confirmed.get(key) ?? 0) >= LEAN_CONFIRM_STREAK;

/** Does this lean read need today's full capture of the same page? Null: the lean read is written. */
export function fallbackFor(state: LeanRunState, lean: FieldReading[]): { reason: 'check' | 'miss' | 'unshown'; fields: string[] } | null {
  const miss = lean.filter((x) => x.hasPaths && x.value === null && !trusted(state, x.key)).map((x) => x.key);
  const unshown = lean.filter((x) => x.value !== null && x.shown === false && !trusted(state, x.key)).map((x) => x.key);
  if (state.checksLeft > 0) return { reason: 'check', fields: [] };
  if (miss.length > 0) return { reason: 'miss', fields: miss };
  if (unshown.length > 0) return { reason: 'unshown', fields: unshown };
  return null;
}

const same = (a: unknown, b: unknown) => JSON.stringify(a) === JSON.stringify(b);
const confirm = (s: LeanRunState, key: string) => s.confirmed.set(key, (s.confirmed.get(key) ?? 0) + 1);

function switchToFull(state: LeanRunState, note: string): void {
  if (state.mode === 'full') return;
  state.mode = 'full';
  state.why = 'switched';
  state.note = note;
  console.warn(`[lean] ${note}: the rest of this run takes the full capture`);
}

/** Compares one page read both ways (spec §3.4) and updates the run's state. */
export function learn(state: LeanRunState, lean: FieldReading[], full: FieldReading[], opts: { check: boolean; url: string }): { disagreed: string[]; rescued: string[] } {
  const byKey = new Map(full.map((x) => [x.key, x]));
  const disagreed: string[] = [];
  const rescued: string[] = [];
  for (const l of lean) {
    const f = byKey.get(l.key);
    if (!f) continue;
    if (l.value === null) {
      if (f.value !== null) { rescued.push(l.key); state.confirmed.delete(l.key); }
      else if (l.hasPaths) confirm(state, l.key);
      continue;
    }
    if (!same(l.value, f.value)) { disagreed.push(l.key); continue; }
    if (l.shown === false && f.shown === true) { rescued.push(l.key); state.confirmed.delete(l.key); }
    else if (l.shown === false && f.shown === false) confirm(state, l.key);
    else if (l.shown !== f.shown) disagreed.push(l.key);
  }
  if (opts.check) state.checksLeft = Math.max(0, state.checksLeft - 1);
  state.rescueStreak = rescued.length > 0 ? state.rescueStreak + 1 : 0;
  if (disagreed.length > 0) switchToFull(state, `lean read ${disagreed.join(', ')} differently on ${opts.url}`);
  else if (state.rescueStreak >= LEAN_RESCUE_STREAK) switchToFull(state, `${LEAN_RESCUE_STREAK} products in a row needed the full capture`);
  return { disagreed, rescued };
}

export function recordOutcome(state: LeanRunState, o: LeanOutcome): LeanOutcome {
  if (o.mode === 'lean') state.counts.lean++;
  else if (o.mode === 'full') state.counts.full++;
  else if (o.reason === 'check' || o.reason === 'miss' || o.reason === 'unshown' || o.reason === 'verdict') state.counts.leanFull[o.reason]++;
  return o;
}

export function leanSummary(runId: string, s: LeanRunState): string {
  const lf = s.counts.leanFull;
  const both = lf.check + lf.miss + lf.unshown + lf.verdict;
  const why = s.mode === 'full' ? ` (${s.why}${s.note ? `: ${s.note}` : ''})` : '';
  return `run ${runId}: lean ${s.counts.lean}, lean+full ${both} (check ${lf.check}, miss ${lf.miss}, unshown ${lf.unshown}, verdict ${lf.verdict}), full ${s.counts.full}${why}`;
}
```

```ts
export function buildReadyCheck(
  fields: VerifiedField[],
  pageUrl: string,
  pageVariant?: PageVariant,
  opts: { preferFirstPathMs?: number; now?: () => number } = {},
): ReadyCheck {
  const withPaths = fields.filter((f) => f.paths.length > 0);
  // Spec 2026-10-13 §5: a field with a default never blocks readiness — its paths may legitimately never resolve on this product — unless no other field would wait at all.
  const blocking = withPaths.filter((f) => f.defaultValue === undefined);
  const certified = blocking.length > 0 ? blocking : withPaths;
  const ctx = { pageUrl, pageVariant };
  const now = opts.now ?? Date.now;
  // Spec 2026-10-23 run speed §3.2: a lean capture reads at once, so a later, higher-ranked path (an API that
  // lands after the JSON-LD) would lose to a lower one it beats on a full capture. With preferFirstPathMs the
  // check, once it would pass, waits up to that long for every field's FIRST path. Per capture: a fresh check each time.
  let basicSince: number | null = null;
  return {
    script: buildXPathProbeScript(certifiedXPaths(fields)),
    isReady: (s: ReadySnapshot) => {
      const probe = (s.probe ?? {}) as XPathProbeResult;
      if (!certified.every((f) => pathsFor(f, pageVariant).some((p) => evaluatePath(f, p, s, probe, ctx) !== null))) return false;
      if (!opts.preferFirstPathMs) return true;
      const firstPaths = withPaths.every((f) => {
        const first = pathsFor(f, pageVariant)[0];
        return first === undefined || evaluatePath(f, first, s, probe, ctx) !== null;
      });
      if (firstPaths) return true;
      basicSince ??= now();
      return now() - basicSince >= opts.preferFirstPathMs;
    },
  };
}
```

```ts
/** Every field from one capture and its XPath probe — the first certified path that reads wins — and the shown flags. `data` is before defaults. */
function evaluateCapture(fields: VerifiedField[], capture: PageCapture, probe: XPathProbeResult): Evaluated {
  const ctx = { pageUrl: capture.url, pageVariant: capture.pageVariant };
  const data: Record<string, unknown> = {};
  const stats: VerifiedExtractionResult['stats'] = [];
  for (const f of fields) {
    data[f.key] = null;
    for (const p of pathsFor(f, capture.pageVariant)) {
      const value = evaluatePath(f, p, capture, probe, ctx);
      if (value === null) { stats.push({ key: f.key, concept: f.concept, path: p, hit: false }); continue; }
      data[f.key] = value;
      stats.push({ key: f.key, concept: f.concept, path: p, hit: true, value });
      break;
    }
  }
  const pageText = pageTextOf(capture.html);
  const shown: Record<string, Shown> = {};
  for (const f of fields) {
    const hit = stats.find((s) => s.key === f.key && s.hit);
    shown[f.key] = hit ? shownOnPage(f, hit.path, hit.value, pageText) : null;
  }
  return { data, stats, shown };
}

const readingsOf = (fields: VerifiedField[], ev: Evaluated): FieldReading[] =>
  fields.map((f) => ({ key: f.key, value: ev.data[f.key] ?? null, shown: ev.shown[f.key] ?? null, hasPaths: f.paths.length > 0 }));

function finish(fields: VerifiedField[], ev: Evaluated, capture: PageCapture, timings: CaptureTimings | null, lean?: LeanOutcome): VerifiedExtractionResult {
  const applied = applyDefaults(ev.data, fields);
  return { data: applied.row, stats: ev.stats, timings, capture, shown: ev.shown, defaulted: applied.defaulted, ...(lean ? { lean } : {}) };
}

 * A page that is not the product page (a wall, a 404, an empty page, another site) is a failed item with its one
 * sentence, never a row of misses: no path is evaluated, so no certified path's hit rate counts a wall against it
 * (review C1, 2026-10-09). Thrown after captureUnderLock reported the verdict, so the host's backoff still learns.

function throwUnlessOk(capture: PageCapture, url: string): void {
  if (capture.verdict.kind !== 'ok') throw new CaptureProblemError(verdictSentence(capture.verdict, url), capture.verdict);

export async function runVerifiedExtraction(
  req: { url: string; fields: VerifiedField[] },
  deps: { browser: IBrowser; capture?: PageCapture; acquireLock?: typeof acquireDomainLock; lean?: LeanRunState },
): Promise<VerifiedExtractionResult> {
  const xpaths = certifiedXPaths(req.fields);
  // Today's evaluation: the saved HTML rendered again, offline, and the certified XPaths run there.
  const renderedProbe = async (c: PageCapture): Promise<XPathProbeResult> =>
    xpaths.length ? await deps.browser.setContentEvaluate<XPathProbeResult>(c.html, buildXPathProbeScript(xpaths)) : {};

  // A capture the caller supplied (variant-check's proof page, holds) was already judged by its own taker.
  if (deps.capture) return finish(req.fields, evaluateCapture(req.fields, deps.capture, await renderedProbe(deps.capture)), deps.capture, null);

  const state = deps.lean;
  const takeFull = async () => {
    const capture = await captureUnderLock(req, deps, state ? 'full-no-pictures' : 'full');
    throwUnlessOk(capture, req.url);
    return { capture, ev: evaluateCapture(req.fields, capture, await renderedProbe(capture)) };
  };

  if (!state || state.mode === 'full') {
    const { capture, ev } = await takeFull();
    const outcome = state ? recordOutcome(state, { mode: 'full', reason: state.why, fields: [], leanMs: null }) : undefined;
    return finish(req.fields, ev, capture, capture.timings ?? null, outcome);
  }

  // Spec 2026-10-23 run speed §3.3: the lean capture first; today's full capture only when the rules say so.
  const leanCapture = await captureUnderLock(req, deps, 'lean');
  const leanMs = leanCapture.timings?.totalMs ?? null;
  const kind = leanCapture.verdict.kind;
  // A wall is never loaded twice: its sentence now, its verdict already fed to the host's backoff.
  if (kind === 'challenge' || kind === 'refused') throwUnlessOk(leanCapture, req.url);

  let reason: LeanReason = 'verdict';
  let fields: string[] = [];
  let leanReadings: FieldReading[] | null = null;
  if (kind === 'ok') {
    const ev = evaluateCapture(req.fields, leanCapture, (leanCapture.probe ?? {}) as XPathProbeResult);
    leanReadings = readingsOf(req.fields, ev);
    const fallback = fallbackFor(state, leanReadings);
    if (!fallback) return finish(req.fields, ev, leanCapture, leanCapture.timings ?? null, recordOutcome(state, { mode: 'lean', reason: null, fields: [], leanMs }));
    reason = fallback.reason;
    fields = fallback.fields;
  }

  // Everything written comes from the full capture: data, shown, defaults, path stats (a rescued miss never
  // counts against a healthy path) and the capture variants read.
  const { capture, ev } = await takeFull();
```
