# v1.1 Backend Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the multimodal extractor legible visual coverage of below-the-fold data via progressive screenshot tiles, and add a human row-selector override backend — without sending oversized/illegible images or changing how the cache scores.

**Architecture:** Part A (tiles): capture the full page as legible ≤1536px tiles, feed tile 0 by default, escalate to lower tiles only for still-unresolved fields (capped). Part B (row selector): a nullable `rowSelector` jsonb column on `domain_intelligence`, a `setRowSelector` mutation to persist a human pick, and `extract` overriding the AI's `row_xpath` with it. Data-quality checks (roadmap item 1) are already implemented — no code, just a roadmap update.

**Tech Stack:** TypeScript, Playwright, Vitest, tRPC v11, Drizzle ORM (drizzle-kit migrations), Anthropic SDK. Packages `@robot/browser`, `@robot/agent`, `@robot/scraper`, `@robot/api`, `@robot/db`.

**Spec:** `docs/superpowers/specs/2026-05-22-v1.1-backend-stability-design.md`.

**Commit convention:** User commits manually; suggested messages only — do not `git commit` unless asked. Stage only named files (never `git add -A`).

```typescript
// packages/browser/src/screenshot-tiles.ts
export const TILE_WIDTH = 1280;
// Under Claude's ~1568px long-edge downscale threshold, so tiles stay sharp.
export const TILE_HEIGHT = 1536;
// Cap total tiles to bound capture work and worst-case AI image cost (~4608px coverage).
export const MAX_TILES = 3;

export type TileClip = { x: number; y: number; width: number; height: number };

/** Slice a page of the given pixel height into legible, non-overlapping vertical tiles. */
export function computeTileClips(pageHeight: number): TileClip[] {
  const h = Math.max(1, Math.floor(pageHeight) || 1);
  const clips: TileClip[] = [];
  for (let i = 0; i < MAX_TILES; i++) {
    const y = i * TILE_HEIGHT;
    if (y >= h) break;
    clips.push({ x: 0, y, width: TILE_WIDTH, height: Math.min(TILE_HEIGHT, h - y) });
  }
  return clips;
}
```

```typescript
        // STEP 3.5: Escalate to lower screenshot tiles for still-missing fields.
        // Tile 0 (above-fold) was used above; lower tiles are sent only when needed,
        // capped by capture (MAX_TILES). Cost is paid once per page-shape, then cached.
        const tiles = capture.screenshotTiles ?? [capture.screenshot];
        for (let t = 1; t < tiles.length; t++) {
          const stillMissing = schemaFields.filter((f) => finalData[f.name] === undefined);
          if (stillMissing.length === 0) break;
          try {
            const tilePlan = await agent.generateSelectors(capture, stillMissing, resolvedPageType, tiles[t]);
            const tileScript = buildExtractionScript(tilePlan);
            const tileResult = await browser.evaluate<{ data: Record<string, unknown>[] }>(
              url, tileScript, { waitUntil: 'networkidle' },
            );
            const tileRow = tileResult.data.length > 0 ? tileResult.data[0] : {};
            for (const fieldDef of tilePlan.fields) {
              const assigned = tryAssign(fieldDef.name, tileRow[fieldDef.name], 'xpath', fieldDef.xpath, 0.7);
              if (!assigned && fieldDef.value !== undefined && fieldDef.value !== null
                  && fieldDef.value !== '' && !isAiPlaceholder(fieldDef.value)) {
                tryAssign(fieldDef.name, fieldDef.value, 'ai-vision', '', 0.5);
              }
            }
            console.log(`[extract] Tile ${t} escalation: ${schemaFields.filter(f => finalData[f.name] !== undefined).length}/${schemaFields.length} resolved`);
          } catch (err) {
            console.error(`[extract] Tile ${t} escalation failed (non-fatal):`, err);
          }
        }
```

```typescript
  setRowSelector: publicProcedure
    .input(z.object({
      domain: z.string().min(1),
      pageType: z.enum(['detail', 'listing']),
      rowXpath: z.string().min(1),
    }))
    .mutation(async ({ ctx, input }) => {

          target: [domainIntelligence.domain, domainIntelligence.pageType],
          set: { rowSelector, updatedAt: new Date() },
        });
      return { ok: true as const };
    }),
```
