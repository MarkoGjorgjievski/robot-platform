# Metering and spend caps per organisation — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Count pages, runs and AI spend per organisation and month, stop an organisation's AI work at a monthly limit staff can set, and show it all to staff in a new ops "Organisations" view.

**Architecture:** `@robot/db` gains `orgs.ai_cap_usd` (migration `0023`). `@robot/agent` gains `capped-agent.ts`: `cappedAgent(agent, { remainingUsd, perCallUsd, orgId })`, a Proxy that projects calls × an estimate before every method call and throws `CapReachedError` when the projection would pass what is left (an in-process registry makes an org's concurrent jobs share the remainder). `@robot/api` gains `src/metering/` — `org-usage.ts` (`usageByOrg` / `orgUsage`, from the recorded rows, no counter table) and `cap-state.ts` (`ORG_AI_CAP_USD`, `effectiveCap`, `orgCapState`, `capStateForSource`, `PLAN_CALL_USD`) — and wires the cap into Verify (`run-source-verification.ts`; `@robot/scraper`'s `runVerification` resolves a refused field `ai_unavailable` without counting a call), `verifyEstimate`, planning (`plan-source.ts`: the run fails with the one new customer sentence) and legacy execution (`start-execution.ts`, `executeRun`'s `stopForCap` breaker). `orgs.setAiCap` (staff only, logged in staff words, reworded for the customer) and `ops.orgs` (opsProcedure) are new and classified. `@robot/app` gets a Runs count on Usage, a staff-only "Monthly AI limit" panel on Settings and the `/ops/orgs` view.

**Tech Stack:** TypeScript ESM; Drizzle + Postgres (postgres-js), drizzle-kit; tRPC v11 + zod 3 + superjson; vitest 4; TanStack Start/Router + React 19, Tailwind v4, shadcn/Base UI (app); Playwright (smokes).

## Global Constraints

- **What is counted** (spec §2.1, verbatim): `metering/org-usage.ts` exports `orgUsage(db, orgId, month)`, with the month in UTC and `monthBounds` reused. `pages` — `captures` rows created in the month, for the org's websites. `runs` — `runs` created in the month for the org's websites, samples (`input_label = 'probe'`) excluded. `aiUsd` — the month's sum of `source_verifications.cost_usd` (by `started_at`) and `runs.cost_usd` (by `created_at`), the same as `usage.byProject`. `jevUsd` — the month's sum of `jev_readings.cost_usd`; staff-only, never counted against the cap. `usage.byProject` and `ops.websites` keep their meaning; `orgUsage` equals the sum of `usage.byProject`'s rows for that org.
- **The cap** (§2.2, verbatim): `orgs.ai_cap_usd numeric(10,2)`, nullable. The effective cap is the org's own value when set; else `ORG_AI_CAP_USD` (env, default `25`); `ORG_AI_CAP_USD=none` means no default cap — an org's own value still applies. `orgCapState(db, orgId)` returns `{ capUsd: number | null; spentUsd; remainingUsd: number | null; reached: boolean }`, where `reached` means `spentUsd >= capUsd`; computed on demand from `orgUsage`, with no counter table.
- **Who sets it** (§2.2, verbatim): staff, through `orgs.setAiCap({ capUsd: number | null })` (null means "use the default"). Allowed: an operator in their own org, or staff in staff mode in a customer's org; anyone else gets `FORBIDDEN`. Logged in staff mode through the existing staff-action logging, in staff words: **"Set the monthly AI limit to $40"**, or **"Reset the monthly AI limit to the default"**. Not on the staff deny list.
- **Where AI stops** (§2.3): `orgIdForSource(db, sourceId)` beside `orgIdForRun` (`export/org-for-export.ts`). Verify reads `orgCapState` before any AI; at the cap, fields that would need AI resolve with `failReason: 'ai_unavailable'` and the existing badge and sentence show, with no new customer copy. During a Verify the agent is wrapped in `cappedAgent(agent, { remainingUsd, perCallUsd })`; before each `proposePaths` it projects `calls × perCallUsd`, and when the projection would pass `remainingUsd` it throws `CapReachedError`; that field resolves `ai_unavailable` and the rest of the Verify carries on. `perCallUsd` is `verifyEstimate`'s `perFieldUsd` (`estAiCostPerFieldUsd(urls.length)`). The projection uses calls × estimate, never the process-wide usage counter. `verifyEstimate.aiAvailable` = key set **and** the cap not reached; staff additionally receive `cap: { capUsd, spentUsd, remainingUsd }` through `moneyFields`. Planning: every model method guarded, `PLAN_CALL_USD = 0.05`; at or past the cap planning stops and the run ends failed with **"This organisation has reached this month's limit for automatic setup. Ask us to raise it."** — the only new customer sentence; a planning step that needs no model call is unaffected. Execution (legacy sources only): the same wrapper at `start-execution.ts`'s agent; a `CapReachedError` fails that item with the planning sentence, and three in a row stop the run (`stopForCap`). Not capped: the judge and the staff CLIs; Jev.
- **Ops** (§2.4, verbatim): `/ops/orgs`, linked from the ops header (the ops rail), read-only, from `ops.orgs` (an `opsProcedure`); one row per org: name, the number of websites, and pages, runs and AI spend this month; the effective cap, with "(default)" when it comes from the env; % used, with a **"Limit reached"** badge at 100 %; Jev spend this month in a muted column; sorted by % used, highest first; the month can be this month or any of the last 6. Org Settings, in staff mode: a **"Monthly AI limit"** panel shows spent / cap / remaining this month, a number field (**"Leave empty to use the default ($25)"**) and Save, using `orgs.setAiCap`. The customer sees neither the panel nor any amount (`showsMoney`).
- **Customer** (§2.5): Usage gains a **"Runs"** count beside "Pages captured", for the month and per project; no money.
- **Safety properties** (§3, verbatim): 1. No org's month AI spend passes its cap by more than one projected call's estimate, whatever the concurrency of its own jobs. 2. A cap never stops work that needs no AI (certified extraction, drift, coverage and website checks, every mechanical Verify). 3. A customer never sees an amount, the cap, or the words "AI", "model" or "budget". 4. Only staff and operators can change a cap, and in staff mode it is logged. 5. Metering is computed from the recorded costs, so it cannot drift from them.
- **Customer copy:** no money, no "AI", no "model", no "budget", no internals (Jev, job, queue, worker, procedure names) in anything a customer receives — an answer the browser receives counts, not only what is drawn. `packages/app/src/customer-copy-sweep.test.ts` and `packages/api/src/isolation/money-sweep.test.ts` stay green; staff-only fields go out through `moneyFields(viewerSeesMoney(ctx), …)`.

## Review Focus

1. **Two AI jobs of one organisation at once in one worker** (two Verifies, or a Verify and a plan, both started while the org had $0.36 left) — a person expects the org's combined spend to stay within one call's estimate of the cap, not each job to spend the whole remainder. → Task 3 tests "RF1: two jobs of one org share what is left" (two).
2. **A mistyped `ORG_AI_CAP_USD`** (`abc`, `-5`, `1e999`, blank) — a person expects a bad value never to mean "no limit": anything but `none` or a non-negative number falls back to $25. → Task 2 test "RF2: a mistyped ORG_AI_CAP_USD never means no limit".
3. **Staff lowering the limit below what the org already spent this month** (limit $25, spent $30) — a person expects "Limit reached", $0 left (never negative), % used above 100, and AI stopped. → Task 2 test "RF3: a cap below the spend is reached, with nothing left" and the "RF3" assertion in Task 5's `ops.orgs` test.
4. **The customer reading "Robot staff activity" after staff changed the limit** — a person expects to see that staff changed something, never the amount, the limit, the word "AI" or a procedure name. → Task 5 test "RF4: the customer reads that a setting changed, never the amount".
5. **Odd amounts typed for the limit** (`40.555`, `-1`, `1e12`, `40.5.0`, empty) — a person expects cents kept on the server ($40.56), a negative or absurd amount refused, empty meaning "use the default", and the panel to say why Save is off. → Task 5 test "RF5: the server keeps cents and refuses a negative or absurd limit" and Task 6 test "RF5: the panel takes dollars and cents only".

```ts
/**
 * Which org owns a website (spec 2026-10-24 metering §2.3): worker jobs resolve their org's monthly AI limit with
 * this, with no session. Null for an unknown website or one with no dataset (a legacy/sandbox source) — that one is
 * not org work and is not limited.
 */
export async function orgIdForSource(db: typeof Database, sourceId: string): Promise<string | null> {
  const row = await db
    .select({ orgId: projects.orgId })
    .from(sources)
    .innerJoin(datasets, eq(sources.datasetId, datasets.id))
    .innerJoin(projects, eq(datasets.projectId, projects.id))
    .where(eq(sources.id, sourceId))
    .limit(1);
  return row[0]?.orgId ?? null;
}
```

```ts
// packages/api/src/metering/org-usage.ts
// What an organisation used in a month (spec 2026-10-24 metering §2.1), counted from the recorded rows — the same
// tables and rules as `usage.byProject`, grouped by org. No counter table: it cannot drift from the costs (§3.5).
// Every measure reaches its org one way: website → dataset → project. A website with no dataset counts nowhere.
import { and, eq, gte, inArray, lt, sql, type SQL } from 'drizzle-orm';
import type { AnyPgColumn } from 'drizzle-orm/pg-core';
import { captures, datasets, jevReadings, projects, runs, sourceVerifications, sources, type Database } from '@robot/db';
import { monthBounds } from '../routers/usage.js';

export type OrgUsage = { pages: number; runs: number; aiUsd: number; jevUsd: number };
export const NO_USAGE: Readonly<OrgUsage> = Object.freeze({ pages: 0, runs: 0, aiUsd: 0, jevUsd: 0 });

/** `YYYY-MM` in UTC — the grain `usage.byProject` takes. */
export function monthKeyOf(now: Date): string {
  return `${now.getUTCFullYear()}-${String(now.getUTCMonth() + 1).padStart(2, '0')}`;
}

// Four decimals in the run and verification cost columns, six in Jev's.
const round4 = (n: number) => Math.round(n * 10_000) / 10_000;
const round6 = (n: number) => Math.round(n * 1_000_000) / 1_000_000;

export async function usageByOrg(db: Database, month: string, orgIds?: string[]): Promise<Map<string, OrgUsage>> {
  if (orgIds && orgIds.length === 0) return new Map();
  const { start, end } = monthBounds(month);
  const inMonth = (col: AnyPgColumn) => and(gte(col, start), lt(col, end));
  const scoped = (extra: SQL | undefined) => and(orgIds ? inArray(projects.orgId, orgIds) : undefined, extra);

  const [pages, ran, verified, runSpend, jev] = await Promise.all([
    db.select({ orgId: projects.orgId, n: sql<number>`count(*)::int` }).from(captures)
      .innerJoin(sources, eq(captures.sourceId, sources.id)).innerJoin(datasets, eq(sources.datasetId, datasets.id)).innerJoin(projects, eq(datasets.projectId, projects.id))
      .where(scoped(inMonth(captures.createdAt))).groupBy(projects.orgId),
    db.select({ orgId: projects.orgId, n: sql<number>`count(*)::int` }).from(runs)
      .innerJoin(sources, eq(runs.sourceId, sources.id)).innerJoin(datasets, eq(sources.datasetId, datasets.id)).innerJoin(projects, eq(datasets.projectId, projects.id))
      // A sample is not a run (spec §2.1); a run with no label is.
      .where(scoped(and(inMonth(runs.createdAt), sql`${runs.inputLabel} IS DISTINCT FROM 'probe'`))).groupBy(projects.orgId),
    db.select({ orgId: projects.orgId, usd: sql<string>`coalesce(sum(${sourceVerifications.costUsd}), 0)` }).from(sourceVerifications)
      .innerJoin(sources, eq(sourceVerifications.sourceId, sources.id)).innerJoin(datasets, eq(sources.datasetId, datasets.id)).innerJoin(projects, eq(datasets.projectId, projects.id))
      .where(scoped(inMonth(sourceVerifications.startedAt))).groupBy(projects.orgId),
    // Every run's spend, samples included — the same as Usage.
    db.select({ orgId: projects.orgId, usd: sql<string>`coalesce(sum(${runs.costUsd}), 0)` }).from(runs)
      .innerJoin(sources, eq(runs.sourceId, sources.id)).innerJoin(datasets, eq(sources.datasetId, datasets.id)).innerJoin(projects, eq(datasets.projectId, projects.id))
      .where(scoped(inMonth(runs.createdAt))).groupBy(projects.orgId),
    db.select({ orgId: projects.orgId, usd: sql<string>`coalesce(sum(${jevReadings.costUsd}), 0)` }).from(jevReadings)
      .innerJoin(sources, eq(jevReadings.sourceId, sources.id)).innerJoin(datasets, eq(sources.datasetId, datasets.id)).innerJoin(projects, eq(datasets.projectId, projects.id))
      .where(scoped(inMonth(jevReadings.createdAt))).groupBy(projects.orgId),
  ]);

  const out = new Map<string, OrgUsage>();
  const of = (orgId: string) => {
    let u = out.get(orgId);
    if (!u) { u = { ...NO_USAGE }; out.set(orgId, u); }
    return u;
  };
  for (const r of pages) of(r.orgId).pages = Number(r.n);
  for (const r of ran) of(r.orgId).runs = Number(r.n);
  for (const r of [...verified, ...runSpend]) of(r.orgId).aiUsd += Number(r.usd);
  for (const r of jev) of(r.orgId).jevUsd += Number(r.usd);
  for (const u of out.values()) { u.aiUsd = round4(u.aiUsd); u.jevUsd = round6(u.jevUsd); }
  return out;
}

export async function orgUsage(db: Database, orgId: string, month: string): Promise<OrgUsage> {
  return (await usageByOrg(db, month, [orgId])).get(orgId) ?? { ...NO_USAGE };
}

/** How many websites each org has (every website in its projects). */
export async function websitesByOrg(db: Database, orgIds: string[]): Promise<Map<string, number>> {
  if (orgIds.length === 0) return new Map();
  const rows = await db.select({ orgId: projects.orgId, n: sql<number>`count(*)::int` }).from(sources)
    .innerJoin(datasets, eq(sources.datasetId, datasets.id)).innerJoin(projects, eq(datasets.projectId, projects.id))
    .where(inArray(projects.orgId, orgIds)).groupBy(projects.orgId);
  return new Map(rows.map((r) => [r.orgId, Number(r.n)]));
}
```

```ts
// packages/api/src/metering/cap-state.ts
// An organisation's monthly AI limit (spec 2026-10-24 metering §2.2): its own value, else ORG_AI_CAP_USD ($25 unless
// set; `none` = no default). The state is computed on demand from what the month recorded — no counter table.
import { eq } from 'drizzle-orm';
import { orgs, type Database } from '@robot/db';
import { orgIdForSource } from '../export/org-for-export.js';
import { monthKeyOf, orgUsage } from './org-usage.js';

export const DEFAULT_ORG_AI_CAP_USD = 25;
/** What one planning (or legacy execution) model call is projected at (spec §2.3). */
export const PLAN_CALL_USD = 0.05;

const round2 = (n: number) => Math.round(n * 100) / 100;
const round4 = (n: number) => Math.round(n * 10_000) / 10_000;
let warned = false;

/** The default limit. Anything but `none` or a non-negative number falls back to $25: a typo never lifts the limit. */
export function defaultCapUsd(env: Record<string, string | undefined> = process.env): number | null {
  const raw = (env.ORG_AI_CAP_USD ?? '').trim();
  if (raw === '') return DEFAULT_ORG_AI_CAP_USD;
  if (raw.toLowerCase() === 'none') return null;
  const n = /^\d+(\.\d+)?$/.test(raw) ? Number(raw) : NaN;
  if (!Number.isFinite(n)) {
    if (!warned) { warned = true; console.warn(`[metering] ORG_AI_CAP_USD=${JSON.stringify(raw)} is not a number or "none"; using $${DEFAULT_ORG_AI_CAP_USD}`); }
    return DEFAULT_ORG_AI_CAP_USD;
  }
  return round2(n);
}

export type CapSetting = { capUsd: number | null; isDefault: boolean; ownCapUsd: number | null; defaultCapUsd: number | null };

export function effectiveCap(own: string | number | null | undefined, env: Record<string, string | undefined> = process.env): CapSetting {
  const ownCapUsd = own === null || own === undefined ? null : Number(own);
  const fallback = defaultCapUsd(env);
  return ownCapUsd === null
    ? { capUsd: fallback, isDefault: true, ownCapUsd: null, defaultCapUsd: fallback }
    : { capUsd: ownCapUsd, isDefault: false, ownCapUsd, defaultCapUsd: fallback };
}

export type CapState = { capUsd: number | null; spentUsd: number; remainingUsd: number | null; reached: boolean };

/** `reached` at equality; what is left never goes below 0 (a limit lowered under the spend has nothing left). */
export function capStateOf(capUsd: number | null, spentUsd: number): CapState {
  if (capUsd === null) return { capUsd: null, spentUsd, remainingUsd: null, reached: false };
  return { capUsd, spentUsd, remainingUsd: Math.max(0, round4(capUsd - spentUsd)), reached: spentUsd >= capUsd };
}

/** % of the limit used, one decimal; a limit of 0 is 100 % used from the start; no limit, none. */
export function percentUsed(capUsd: number | null, spentUsd: number): number | null {
  if (capUsd === null) return null;
  if (capUsd === 0) return 100;
  return Math.round((spentUsd / capUsd) * 1000) / 10;
}

export async function orgCapState(db: Database, orgId: string, now: Date = new Date()): Promise<CapState> {
  const org = await db.query.orgs.findFirst({ where: eq(orgs.id, orgId), columns: { aiCapUsd: true } });
  const { capUsd } = effectiveCap(org?.aiCapUsd ?? null);
  const { aiUsd } = await orgUsage(db, orgId, monthKeyOf(now));
  return capStateOf(capUsd, aiUsd);
}

/** For a worker job, which has no session: the website's org, or no limit for a website with no org. */
export async function capStateForSource(db: Database, sourceId: string, now: Date = new Date()): Promise<CapState & { orgId: string | null }> {
  const orgId = await orgIdForSource(db, sourceId);
  if (!orgId) return { orgId: null, capUsd: null, spentUsd: 0, remainingUsd: null, reached: false };
  return { orgId, ...(await orgCapState(db, orgId, now)) };
}
```

```ts
// packages/agent/src/capped-agent.ts
// An organisation's monthly AI limit, at the call (spec 2026-10-24 metering §2.3). `cappedAgent` wraps an agent: before
// each method call — every method of an agent here is a model call — it projects this job's calls × a per-call
// estimate, plus what the org's other jobs in this process projected that this job's remainder could not see, and
// refuses the call (CapReachedError) when that would pass what was left when the job started. Projections, never the
// process-wide usage counter (usage.ts): that counter is shared by every job in flight.
//
// One process only: several worker processes do not see each other's open jobs (spec §3.1 holds per process).

export class CapReachedError extends Error {
  constructor(message = "This organisation's monthly limit is reached.") {
    super(message);
    this.name = 'CapReachedError';
  }
}

export function isCapReached(err: unknown): boolean {
  return err instanceof CapReachedError || (err instanceof Error && err.name === 'CapReachedError');
}

export type CapOptions = {
  /** What was left of the month's limit when the job started; null = no limit (counted, never refused). */
  remainingUsd: number | null;
  /** What one call is projected at. */
  perCallUsd: number;
  /** The org the job works for: its open jobs in this process share the remainder (spec §3.1). */
  orgId?: string | null;
};

export type CapLedger = {
  readonly calls: number;
  readonly refused: number;
  /** calls × perCallUsd */
  readonly projectedUsd: number;
  /** One more call made outside the agent (catalogue discovery); throws CapReachedError when refused. */
  reserve(): void;
  /** The job's cost is recorded — call it after writing the cost. */
  close(): void;
};

const SCALE = 10_000;
const units = (usd: number) => Math.round(usd * SCALE);

type Entry = { ledger: Ledger; openedAt: number; closedAt: number | null };
let tick = 0;
const byOrg = new Map<string, Entry[]>();

class Ledger implements CapLedger {
  calls = 0;
  refused = 0;
  private readonly entry: Entry | null;

  constructor(private readonly opts: CapOptions) {
    this.entry = opts.orgId ? { ledger: this, openedAt: ++tick, closedAt: null } : null;
    if (this.entry) byOrg.set(opts.orgId!, [...(byOrg.get(opts.orgId!) ?? []), this.entry]);
  }

  get projectedUsd(): number {
    return (this.calls * units(this.opts.perCallUsd)) / SCALE;
  }

  /** The org's other jobs this job's remainder did not see: still open, or closed after this one started. */
  private othersUnits(): number {
    if (!this.entry) return 0;
    let sum = 0;
    for (const e of byOrg.get(this.opts.orgId!) ?? []) {
      if (e === this.entry) continue;
      if (e.closedAt === null || e.closedAt > this.entry.openedAt) sum += e.ledger.calls * units(e.ledger.opts.perCallUsd);
    }
    return sum;
  }

  reserve(): void {
    const { remainingUsd, perCallUsd } = this.opts;
    if (remainingUsd !== null) {
      const left = units(remainingUsd);
      const projected = (this.calls + 1) * units(perCallUsd) + this.othersUnits();
      if (left <= 0 || projected > left) {
        this.refused++;
        throw new CapReachedError();
      }
    }
    this.calls++;
  }

  close(): void {
    if (!this.entry || this.entry.closedAt !== null) return;
    this.entry.closedAt = ++tick;
    prune(this.opts.orgId!);
  }
}

/** A closed job is kept only while a job that started before it closed is still open. */
function prune(orgId: string): void {
  const list = byOrg.get(orgId) ?? [];
  // `Math.min()` of nothing is Infinity: with no open job every closed entry goes.
  const oldestOpen = Math.min(...list.filter((e) => e.closedAt === null).map((e) => e.openedAt));
  const kept = list.filter((e) => e.closedAt === null || e.closedAt > oldestOpen);
  if (kept.length > 0) byOrg.set(orgId, kept);
  else byOrg.delete(orgId);
}

const ledgers = new WeakMap<object, CapLedger>();

export function cappedAgent<T extends object>(agent: T, opts: CapOptions): T {
  const ledger = new Ledger(opts);
  const proxy = new Proxy(agent, {
    get(target, prop, receiver) {
      const value = Reflect.get(target, prop, receiver);
      if (typeof value !== 'function' || prop === 'constructor') return value;
      return (...args: unknown[]) => {
        // A rejected promise, never a synchronous throw: `agent.x().catch(…)` must see the refusal.
        try { ledger.reserve(); } catch (err) { return Promise.reject(err); }
        // `this` is the proxy, so a method that calls another (generateSelectors → locateResults) is two calls.
        return (value as (...a: unknown[]) => unknown).apply(receiver, args);
      };
    },
  });
  ledgers.set(proxy, ledger);
  return proxy;
}

export function capLedgerOf(agent: object): CapLedger | undefined {
  return ledgers.get(agent);
}

/** Tests only: forget every open job. */
export function resetCapLedgers(): void {
  byOrg.clear();
  tick = 0;
}
```

```ts
// The staff-only "Monthly AI limit" panel on the organisation's Settings (spec 2026-10-24 metering §2.4). Pure. A
// customer never sees it: Settings draws it for operators only.
import { usdLabel } from './usage-view';

/** `ops.orgs`' row for the org: the fields the panel reads. */
export type AiLimitRow = { capUsd: number | null; capIsDefault: boolean; ownCapUsd: number | null; defaultCapUsd: number | null; aiUsd: number; remainingUsd: number | null; reached: boolean };

export const AI_LIMIT_TITLE = 'Monthly AI limit';
const AMOUNT = 'Enter an amount in dollars, like 40 or 40.50';

/** "$25", "$40.50" — the limit as staff type it (the api's staff log writes it the same way). */
export function capText(usd: number): string {
  return Number.isInteger(usd) ? `$${usd}` : `$${usd.toFixed(2)}`;
}

export function defaultHint(defaultCapUsd: number | null): string {
  return defaultCapUsd === null ? 'Leave empty for no limit' : `Leave empty to use the default (${capText(defaultCapUsd)})`;
}

/** Empty is "use the default"; anything else is dollars with at most two decimals, up to $1,000,000. */
export function parseCapDraft(draft: string): { ok: true; capUsd: number | null } | { ok: false; reason: string } {
  const t = draft.trim().replace(/^\$\s*/, '');
  if (t === '') return { ok: true, capUsd: null };
  if (!/^\d+(\.\d{1,2})?$/.test(t)) return { ok: false, reason: AMOUNT };
  const n = Number(t);
  if (n > 1_000_000) return { ok: false, reason: 'At most $1,000,000' };
  return { ok: true, capUsd: n };
}

/** `draft` null: untouched — the field shows the org's own limit, or nothing when it uses the default. */
export function aiLimitView(row: AiLimitRow | null, draft: string | null) {
  const shown = draft ?? (row?.ownCapUsd != null ? String(row.ownCapUsd) : '');
  const parsed = parseCapDraft(shown);
  const unchanged = parsed.ok && parsed.capUsd === (row?.ownCapUsd ?? null);
  return {
    draft: shown,
    spentLine: row ? `${usdLabel(row.aiUsd)} spent this month` : '',
    capLine: !row ? '' : row.capUsd === null ? 'No limit' : `${capText(row.capUsd)} limit${row.capIsDefault ? ' (default)' : ''}`,
    remainingLine: row && row.remainingUsd !== null ? `${usdLabel(row.remainingUsd)} left` : '',
    reached: row?.reached ?? false,
    hint: defaultHint(row ? row.defaultCapUsd : null),
    saveReason: !row ? 'Loading…' : !parsed.ok ? parsed.reason : unchanged ? 'No changes to save' : null,
    capUsd: parsed.ok ? parsed.capUsd : null,
  };
}
```

```ts
// The ops "Organisations" view (spec 2026-10-24 metering §2.4): staff only. Pure. Mirrors `ops.orgs`' row (the app's
// views re-declare the api's shapes, like ops-view.ts).
import { monthKey, monthLabel, pagesLabel, runsLabel, shiftMonth, usdLabel } from './usage-view';
import { capText } from './ai-limit-view';

export type OpsOrgRow = {
  org: { id: string; name: string; slug: string };
  websites: number; pages: number; runs: number; aiUsd: number; jevUsd: number;
  capUsd: number | null; capIsDefault: boolean; ownCapUsd: number | null; defaultCapUsd: number | null;
  remainingUsd: number | null; percentUsed: number | null; reached: boolean;
};

export const LIMIT_REACHED = 'Limit reached';

export function capCell(r: Pick<OpsOrgRow, 'capUsd' | 'capIsDefault'>): string {
  if (r.capUsd === null) return 'No limit';
  return r.capIsDefault ? `${capText(r.capUsd)} (default)` : capText(r.capUsd);
}

export function percentCell(p: number | null): string {
  if (p === null) return '—';
  if (p > 0 && p < 1) return '<1%';
  return `${Math.round(p)}%`;
}

/** Labels only; the api orders the rows (highest % first, no limit last, then name). */
export function opsOrgsView(rows: readonly OpsOrgRow[]) {
  return rows.map((r) => ({
    id: r.org.id,
    name: r.org.name,
    websitesLabel: `${r.websites} ${r.websites === 1 ? 'website' : 'websites'}`,
    pagesLabel: pagesLabel(r.pages),
    runsLabel: runsLabel(r.runs),
    aiLabel: usdLabel(r.aiUsd),
    capLabel: capCell(r),
    percentLabel: percentCell(r.percentUsed),
    reached: r.reached,
    jevLabel: r.jevUsd === 0 ? '—' : usdLabel(r.jevUsd),
  }));
}

/** This month and the six before it, newest first (UTC, as `usage.byProject` keys months). */
export function opsOrgMonths(now: Date): Array<{ key: string; label: string }> {
  const current = monthKey(now);
  return Array.from({ length: 7 }, (_, i) => {
    const key = shiftMonth(current, -i);
    return { key, label: monthLabel(key) };
  });
}

export function matchesOrgQuery(row: Pick<OpsOrgRow, 'org'>, query: string): boolean {
  const q = query.trim().toLowerCase();
  return !q || row.org.name.toLowerCase().includes(q) || row.org.slug.toLowerCase().includes(q);
}
```

## Settled here (spec ambiguities, decided for this plan)

1. **"Builds no agent, exactly like a keyless Verify" vs "fields resolve `ai_unavailable`".** A `null` agent leaves AI fields with no `failReason` (the keyless "not verified" badge), so at the limit Verify passes a capped wrapper around a stub (`NO_MODEL`) whose every call is refused before it is made: no `SchemaAgent` is built, no call is made, and AI fields read the existing `ai_unavailable` badge and sentence. Keyless and `free` Verifies still get `null`.
2. **A refused call is not a call.** `runVerification` resolves a field the limit refused `ai_unavailable` without `aiCalled: true` and without counting it in `aiCalls` (never sent, never billed). A call that was sent and failed is still counted (spec 2026-10-20 §3.3, unchanged).
3. **Safety property 1 under concurrency.** Each job's `remainingUsd` comes from the database when it starts, which cannot see other open jobs' calls (costs are written when a job ends). `cappedAgent` therefore keeps an in-process registry per org: a job's projection adds the calls of the org's other jobs that are open, or closed after it started; a job closed before it started is already in its remainder. Several worker processes do not share it (Open); a job that crashes before `close()` keeps its projection until restart (the safe direction).
4. **Edges of the limit:** `reached` at `spentUsd >= capUsd`; what is left is clamped at 0; a limit of 0 means no AI at all (100 % used from the start); a limit lowered below the spend reads above 100 %.
5. **A mistyped `ORG_AI_CAP_USD`** (not `none`, not a non-negative decimal) falls back to $25 with one warning — never to "no limit". Values are rounded to cents.
6. **Planning at the limit fails the run, it does not throw.** `planRun` keeps walking past a failed model step, so `planSource` checks the ledger after the walk: any refusal → the run is `failed` with the sentence, no items and `logs: null` (the walk's warnings would name the model step); the result is `status: 'failed'`. A thrown error would make the `plan` job retry. A walk that made no model call is planned, even at a limit of 0.
7. **Legacy execution:** the per-call estimate is `PLAN_CALL_USD`; an item whose model call was refused fails with the sentence even when the chain read something mechanically, and its extraction row is deleted so a failed item adds no rows; catalogue discovery (a direct API call outside the agent) is reserved through the ledger (`reserveAiCall`); the breaker (`CAP_STREAK_LIMIT = 3`, `stopForCap`) shares the wall breaker's write (`failPendingForWall`: "Not tried: <sentence>").
8. **Where the words live:** `CAP_REACHED_MESSAGE` is in `@robot/scraper/customer-copy` (swept by the app's copy sweep, passed through by `captureWords`); `CapReachedError`'s own default message is neutral ("This organisation's monthly limit is reached.") so a swallowed refusal never puts "AI" into a warning.
9. **Who may set the limit:** `ctx.isOperator` — an operator in their own org, staff mode included (a staff session's user is an operator by construction); no role check; anyone else `FORBIDDEN` ("Operators only").
10. **Amounts:** the server takes 0–1,000,000, finite, and rounds to cents (`40.555` → `40.56`); the panel takes dollars with at most two decimals (an optional `$`), empty = the default; the staff log writes `$40` for whole dollars and `$40.50` otherwise.
11. **The customer's staff log:** spec property 3 beats "logged in staff words, shown to the customer": the customer's `orgs.staffActivity` reads `orgs.setAiCap` rows as "Changed a setting of this organisation" (`CUSTOMER_SUMMARIES`) and never receives the `action` key; ops reads the stored sentence.
12. **The panel's data:** no new procedure — the panel reads `ops.orgs({ orgId })` (operators only) and is drawn only when `session.isOperator`.
13. **`ops.orgs`:** a past month's % is against today's limit; "websites" counts every website in the org's projects; sorted by % used, highest first, no limit last, then name; the server accepts any `YYYY-MM`, the screen offers this month and six before; a name filter (`q`) is added so the staff smoke's screenshot shows only its throwaway org.
14. **Classification:** `orgs.setAiCap` is `org-wide` with `refuses: 'FORBIDDEN'` (the `org-wide` type gains that refusal; the fixture's owner is a plain customer); `ops.orgs` is `ops`; both stay in the `session` rate group (neither starts work). Neither is on the deny list.
