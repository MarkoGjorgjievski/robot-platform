A: Three-Column (Current Layout)

Runs left, Logs/Data center, Inputs right. All visible simultaneously. Each input has its own Run button.

B: Two-Column (Runs + Tabbed Content)

Runs list fixed on left. Right side has tabs: Logs, Data, Inputs. Inputs become a tab instead of always-visible panel. More space for logs/data.

C: Full-Width Tabs

Single panel with tabs across the top: Runs, Logs, Data, Inputs. Full width for each view. Simpler but only one thing visible at a time.

Key differences

  • A — Inputs always visible, easy to trigger runs. But tighter space for logs.
  • B — Runs always visible (to click and load DOM). Inputs tucked in a tab. Best balance.
  • C — Maximum space per view, but you can't see runs while viewing logs.
