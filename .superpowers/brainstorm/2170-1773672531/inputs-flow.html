How it works

  • First input: User defines both keys and values. Keys become the "template" for this extractor's inputs.
  • Subsequent inputs: "+ Add input" creates a new row with keys pre-filled from input-1. User only fills values.
  • Key names are read-only on subsequent inputs (shown as labels, not editable fields).
  • Edit (✎) expands any saved input to edit its values.
  • Run (▶) triggers a run with that specific input.
  • Save & Run saves the new input and immediately queues a run.
